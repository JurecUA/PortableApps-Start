# Сборка PortableApps Start

## Состояние инструкции

Это предварительная инструкция для этапа подготовки документации. Сборка `.exe` ещё не доступна: архивы исходников PortableApps 30.4 не были извлечены и изучены.

## Что известно

SourceForge публикует отдельные архивы Platform, Start и Updater 30.4. В официальном журнале изменений проекта указано, что в версии 30.3 компилятор обновлён до Delphi 13.1. Это подтверждает основную линию компилятора для 30.4, но не раскрывает требуемую редакцию IDE, установленные компоненты или упаковщик.

## Что установить сейчас

- Delphi 13.1 (линейка Embarcadero RAD Studio) как компилятор, используемый платформой 30.4.
- Git для получения исходников и фиксации версий.
- 7-Zip для распаковки архивов `.7z`.

До проверки файлов проектов и скриптов не выбирайте редакцию Delphi и не устанавливайте дополнительные инструменты (например, Visual Studio или NSIS) наугад. После аудита инструкция будет дополнена точными компонентами, источниками загрузки и командами сборки.
