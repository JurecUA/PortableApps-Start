# Сборка PortableApps Start

## Состояние инструкции

Исходники 30.4 получены и распакованы. Сборка `.exe` ещё не выполнялась: требуется установить/проверить Delphi и подтвердить компоненты контрольной сборкой.

## Что известно

Platform и Start — проекты Delphi VCL с `.dproj`, настроенные на Win32/x86; Start запускает `PortableAppsPlatform.exe` в структуре PortableApps. Updater 30.4 собирается из NSIS `.nsi` с локальными `.nsh`. Журнал изменений указывает Delphi 13.1 для ветки 30.4; редакция IDE и состав компонентов пока не подтверждены контрольной сборкой.

## Что установить сейчас

- Embarcadero RAD Studio / Delphi 13.1 с Win32 compiler и MSBuild; редакцию и компоненты подтвердить перед установкой.
- Git для получения исходников и фиксации версий.
- 7-Zip для распаковки архивов `.7z`.
- NSIS нужен только для пересборки Updater из предоставленного сценария.

По имеющимся проектам Visual Studio не требуется для сборки Platform/Start. Сборка пока не проверялась; инструкцию уточним после контрольной сборки Win32.
