# PortableApps Start

Проект форка PortableApps Platform 30.4 с компактной оболочкой в духе меню «Пуск» Windows 11.

## Состояние

Текущая версия `0.1.5` — добавлены исходники Platform, Start и Updater 30.4, статический аудит основных функций и точный список для подготовки Win32-сборки. Исполняемый файл пока не собран: на этом компьютере нет Delphi compiler.

## Решения проекта

- Основа: PortableApps Platform 30.4.
- Запуск: обычным способом через PortableApps; после закрытия окна приложение остаётся в системном трее.
- Приоритет: сохранить обнаружение, запуск, обновление и архивирование приложений и совместимость пользовательских данных.
- Иконка: четыре плитки в силуэте переносного накопителя.

## Иконка

`assets/portableapps-start.svg` — исходный векторный вариант. Для окон и трея из него потребуется сгенерировать `.ico` нужных размеров после выбора графических средств, совместимых с установленной сборочной цепочкой 30.4.
