# PortableApps Start

Проект форка PortableApps Platform 30.4 с компактной оболочкой в духе меню «Пуск» Windows 11.

## Состояние

Текущая версия `0.1.2` — этап подготовки: предварительный аудит исходников и план реализации. Исполняемый файл пока не собирается. Исходные архивы Platform, Start и Updater 30.4 ещё требуется получить и проверить.

## Решения проекта

- Основа: PortableApps Platform 30.4.
- Запуск: обычным способом через PortableApps; после закрытия окна приложение остаётся в системном трее.
- Приоритет: сохранить обнаружение, запуск, обновление и архивирование приложений и совместимость пользовательских данных.
- Иконка: четыре плитки в силуэте переносного накопителя.
